# Bank Account Management System

## Overview

This is a command-line Bank Account Management System developed using Core Java. 
The project demonstrates object-oriented programming concepts by simulating basic banking operations.

## Features

- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- Validate account operations using custom exceptions

## Technologies Used

- Java
- Eclipse IDE
- Object-Oriented Programming (OOP)

## Project Structure

```
src/
└── mini_project/
    ├── Account.java
    ├── AccountException.java
    ├── AccountService.java
    └── TestAccount.java
```

## Concepts Demonstrated

- Classes and Objects
- Encapsulation
- Custom Exception Handling
- Packages
- Method Overloading/Calling (if applicable)

## How to Run

1. Clone the repository.
2. Open the project in Eclipse or any Java IDE.
3. Run `TestAccount.java`.
